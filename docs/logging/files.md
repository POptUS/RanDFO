# Log Files

| File | Description |
|---|---|
| `deterministic_eval_log.csv` | Evaluations for deterministic runs |
| `montecarlo_eval_log.csv` | Sample-by-sample evaluations for MC runs |
| `progress_log.csv` | Trust-region size, model updates, etc. |
| `monte_carlo_estimates_log.csv` | Mean/std of MC estimates per point |
| `objfun_log.txt` | Text log of all sampled values |

Logs are written under `logs/`.
